SDStudio & NAIS scenes

Converts NovelAI scene presets between SDStudio projects and NAIS2/NAIS3 scene files, in both directions. Your files are read in this browser and never uploaded.

Use a plain name: no dots, spaces or angle brackets.

Loading the results

SDStudio, .sdstudio.json
Drop the file on the SDStudio window and pick 새 프로젝트로 임포트 (new project) or 현재 프로젝트에 씬만 임포트 (scenes only, into the open project; scenes with the same name are replaced).
NAIS3, .nais.json
Scene mode, Import Scenes. The scenes are added to the open preset, so make an empty one first. Fragments: Import Fragment TXT with the .fragments.zip.
NAIS2, .nais.json
Scene mode, Import JSON, or drop the file. It becomes a new preset.

What changes

  • Variants. An SDStudio scene with N prompt variants becomes N NAIS scenes, name_1 to name_N, the same split NAIS makes on its own import. SDStudio queues every variant, so you get the same images.
  • Wildcards. SDStudio only reads <library.piece>. NAIS <eyes> becomes <nais.eyes> and turns back into <eyes> on the way home.
  • Left behind. SDStudio style presets and character prompts, disabled variants, inpaint scenes and images. NAIS per-scene negatives and # comment lines. Each file lists what it dropped.
